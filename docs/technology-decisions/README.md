# Component and dependency records

Record implementation-specific dependency decisions here. Product requirements
and architecture decisions stay in the Obsidian vault.

For each adopted open-source component, record its source/documentation URL,
version, license, purpose, local customization, accessibility verification, and
upgrade notes. Use a descriptive filename such as rental-card-components.md.
See [foundation.md](foundation.md) for the installed framework/UI/map tools,
local customizations, licenses, and upgrade considerations.
